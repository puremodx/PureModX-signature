PUREKILLER MT MANAGER HOOKLINE

Add these four classes to the target DEX:
- SignatureGuard.smali
- RemoteSignatureGuard.smali
- PureKillerStartup.smali
- PureKillerWorker.smali

Add android.permission.INTERNET inside the existing manifest's <manifest> element.

In the target app's existing onCreate method, insert this one line AFTER the existing invoke-super call:
invoke-static {p0}, Lcom/puremodx/purekiller/PureKillerStartup;->start(Landroid/content/Context;)V

The line uses p0 and allocates no additional registers. Do not replace the original onCreate method. If onCreate is an Activity method, insert after super.onCreate(Bundle); if it is Application.onCreate, insert after super.onCreate().
